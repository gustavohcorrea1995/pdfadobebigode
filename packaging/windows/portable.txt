PDFDOBIGODE portable mode

While this file sits next to pdfdobigode.exe, PDFDOBIGODE keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfDoBigodeData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PDFDOBIGODE with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\PDFDOBIGODE and
%LOCALAPPDATA%\PDFDOBIGODE) instead. If PdfDoBigodeData can't be written (for example on a read-only
drive), PDFDOBIGODE says so and uses the per-user folders instead.
